      UniFi Access Point 7.0.47

      Source: UniFi Access Point/Switch/LTE | Releases | Ubiquiti Community | Date: 2024-03-21 |

      Overview UniFi Access Point 7.0.47 improved temperature management and is only avaialble for Gen7 Access Points. Improvements Improved device temperature management. Known issues SSIDs using RADIUS assigned VLANs or on different VLANs from the native VLAN may operate at slower than expected speeds. This is our top priority to resolve. Additional information Refer to the Help Center article here to determine the UniFi Access Point generation. Update your devices by changing the Device Firmware Release Channel in the UniFi Network application to Release Candidate. If you wish to go back to the Official release after the upgrade, change the release channel back to Official. If you encounter any issues with this release, please provide us with some details on your setup and include the below information: AP model(s) Previous AP release version UniFi Network application version

  • 2024-03-14

      UniFi Switch 7.0.44

      Source: UniFi Access Point/Switch/LTE | Releases | Ubiquiti Community | Date: 2024-03-14 |

      Overview UniFi Switch 7.0.44 adds support for Global ACL Rules on L3 switches. Improvements Added support for Global ACL Rules. This requires Network Application 8.1.113 or newer. Added a new PoE current-usage screen on the touchscreen. Added PoE Off state on the touchscreen. Improved SFP module compatibility. [USW-Pro-Max] Added support for Port Locating on the touchscreen. [USW-Enterprise-8-PoE] Improved device stability after config provision. [USW-Pro-Aggregation] Improved SFP28 link stability for manual speed 25Gbps ports. [USW-Gen1/USW-Pro] Improved CPU usage when forwarding PTPv2 traffic. [USW] Increased the maximum number of LAG groups. Bugfixes Fixed unexpected log spam related to memory checks. [USW-Enterprise-24-PoE] Fixed an issue where wireless clients couldn't roam when Restricted by MAC ID is enabled on the port that an AP is connected to. [USW-Pro-Max] Fixed Etherlighting not working if the port speed is 10Mbps. [USW-Pro-Max] Fixed an issue where routing to other L3 networks may not work after a reboot. [USW-Pro-Max] Fixed Port Native VLAN not working when VLAN Magic settings are configured. [USW-Pro] Fixed occasional device freezes during firmware updates. [USW-Enterprise-8-PoE] Fixed incorrect STP path cost when STP mode is running. [USP-PDU-Pro] Fixed not showing power utilization on ports where lower power consumption devices are connected. Known issues You might experience slow memory increase on USW-Pro-Max switches, this will be fixed in a upcoming firmware release. Additional information Your device built-in display may turn black or unresponsive for ~10 minutes after firmware upgrades to upgrade Touchscreen firmware. Your device's Etherlighting ports may turn off for ~5 minutes after firmware upgrades to upgrade the Etherlighting firmware.   If you encounter any issues with this release, please provide us some details on your setup and include the below information: Switch model(s) Previous Switch release version UniFi Network application version
