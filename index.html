      UniFi Access Point for U7-LR 8.0.74

      Source: UniFi Access Point | Releases | Ubiquiti Community | Date: 2026-07-07 |

      Improvements Improved client connectivity and roam event reporting. Improved Auto-Link compatibility. Improved connectivity for legacy IoT clients. Improved stability. Bugfixes Fixed an issue where Auto Channel Selection on 2.4 GHz could select restricted channels. Fixed connectivity issues where UDB-IoT clients could not access the internet. Fixed an issue where UDB-IoT clients could not reach DVLAN clients on UAP devices. Fixed an issue where bandwidth was not synchronized on meshed APs. Fixed an issue causing clients to get stuck in a roaming loop between 2.4 GHz and 5 GHz. Fixed an issue where clients could not connect using OWE. Fixed an issue where SSIDs failed to broadcast when MLO and Fast Roaming were enabled. Fixed an issue where OWE association could cause the AP to reboot. Fixed an issue where Lock to AP failed to keep clients locked after roaming. Fixed an issue where the 2.4 GHz radio continued broadcasting after being disabled. Fixed an issue where Fast Roaming could cause SSIDs to fail to broadcast. Fixed an issue where MLO clients could create ghost clients in the clients list. Additional information Update your devices by changing the Device Firmware Release Channel in the UniFi Network application to Release Candidate. If you wish to go back to the Official release after the upgrade, change the release channel back to Official.
