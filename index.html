      UniFi Access Point 6.7.17

      Source: UniFi Access Point | Releases | Ubiquiti Community | Date: 2025-04-22 |

      Overview This release is only for these models: U6-LR/U6-Lite/U6+/U6-LR+ UAP-nanoHD/FlexHD/BeaconHD/IW-HD Improvements Added packet capture support. * Eliminate client connectivity disruption when adding, deleting, editing or pausing wireless networks. Improved TX Retries reporting. Improved the 5GHz auto-channel selection algorithm ensuring a less noisy channel selection. Updated regulatory information for Indonesia. Updated regulatory information for Brazil. Updated regulatory information for Taiwan. Improved AP stability. Bugfixes Fixed incorrect rate selection. Fixed Outdoor Mode incorrect channel selection after a DFS event. Fixed Proxy ARP issue with DHCP BOOTP packets. Fixed authentication failures when RADIUS MAC Auth + WPA2/WPA3-Enterprise security are used together and a local gateway RADIUS server is used for user authentication. Fixed an issue where the UniFi Network application reports a duplicate IP address alert. Fixed ARP broadcast control when Multicast and Broadcast Control and Client Device Isolation are enabled. Fixed DHCP offers being dropped when a U6+ is acting as a wireless uplink AP. Additional information Unless indicated otherwise, improvements and fixes apply to all AP models. * Supported models: U6-Lite, U6-LR, U6+. ——— Update your devices by changing the Device Firmware Release Channel in the UniFi Network application to Release Candidate. If you wish to go back to the Official release after the upgrade, change the release channel back to Official.
