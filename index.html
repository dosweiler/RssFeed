      UniFi Access Point (all U7 models) 8.0.19

      Source: UniFi Access Point | Releases | Ubiquiti Community | Date: 2025-03-03 |

      Overview UniFi Access Point 8.0.19 introduces the Multi-Link Operation (MLO) feature and includes further improvements for 2.4 GHz IoT connectivity. This is the initial release for the U7-Lite and U7-In-Wall products. Firmware updates will be rolled out gradually for individual models. Improvements Improved client connectivity. Improved AP stability.  Bugfixes Fixed an issue causing inter-client communication to drop. Fixed cloud connectivity for some IoT devices. Additional information NOTE: For the best connectivity and roaming experience when using MLO (Multi-Link Operation) mode, it is required to enable WPA3 or WPA3 Enterprise security mode. When MLO is selected, the UniFi Network application will automatically enforce this security mode. ——— If you encounter any issues with this release, please provide us with some details on your setup and include the below information: AP model(s) Previous AP release version UniFi Network application version UniFi Console Support File (as private attachment)

      UniFi Access Point (all U7 and E7 models) 8.0.19

      Source: UniFi Access Point | Releases | Ubiquiti Community | Date: 2025-03-01 |

      Overview UniFi Access Point 8.0.19 introduces the Multi-Link Operation (MLO) feature and includes further improvements for 2.4 GHz IoT connectivity. Improvements Improved client connectivity. Improved AP stability.  Bugfixes Fixed an issue causing inter-client communication to drop. Fixed cloud connectivity for some IoT devices. Additional information NOTE: For the best connectivity and roaming experience when using MLO (Multi-Link Operation) mode, it is required to enable WPA3 or WPA3 Enterprise security mode. When MLO is selected, the UniFi Network application will automatically enforce this security mode. ——— Update your devices by changing the Device Firmware Release Channel in the UniFi Network application to Release Candidate. If you wish to go back to the Official release after the upgrade, change the release channel back to Official. If you encounter any issues with this release, please provide us with some details on your setup and include the below information: AP model(s) Previous AP release version UniFi Network application version UniFi Console Support File (as private attachment)
