      UniFi Access Point for U6-LR, U6-Lite, U6+ & more 6.7.31

      Source: UniFi Access Point | Releases | Ubiquiti Community | Date: 2025-09-23 |

      Overview This release is only for these models: U6-LR/U6-Lite/U6+ UAP-nanoHD/FlexHD/BeaconHD/IW-HD Improvements Added Channel AI support. Added Roaming Assistant support. Added Quick Airtime Scan support. No client disconnects during scan. Improved overall AP stability. Improved client connectivity performance. Updated regulatory compliance for Brazil. Bugfixes Fixed NanoHD incorrectly selecting channel bandwidth after a DFS event. Fixed U6+ reporting disconnect/reconnect events when clients roam between bands. Fixed upgrade issue on U6+. Fixed Proxy ARP issue when a station has multiple IP addresses. Fixed RADIUS timeout issue when multiple servers are used. Fixed RADIUS accounting issue with incorrect values. Fixed RADIUS accounting issue where values were missing from STOP messages. Additional information If you encounter any issues with this release, please provide us with some details on your setup and include the below information: AP model(s) Previous AP release version UniFi Network application version
