      UniFi Access Point (U7-LR) 8.0.56

      Source: UniFi Access Point | Releases | Ubiquiti Community | Date: 2025-08-26 |

      Improvements Improved Airtime Scan. No client disconnects during scan. Improved MLO performance for some clients. Custom TX power for 2.4 GHz can now be set to 26dBm. Improved AP stability. Bugfixes Fixed an issue in which the AP would not respond to neighbor-report requests. Fixed an issue in which the AP could not wirelessly adopt E7-series devices. Fixed SSID does not broadcast sometimes after configuration changes. Fixed Min RSSI behavior with MLO clients. Fixed WiFi Speed Limit failure on MLO clients. Fixed Ethernet link going down when using 10/100Mbps full-duplex and auto-negotiation is off. Additional information If you encounter any issues with this release, please provide us with some details on your setup and include the below information: AP model(s) Previous AP release version UniFi Network application version
