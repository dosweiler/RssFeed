      UniFi Access Point (all U7 and E7 models) 8.6.9

      Source: UniFi Access Point | Releases | Ubiquiti Community | Date: 2026-05-07 |

      Improvements Added DNS Assistance. Improved delivery of broadcast DHCP offers to wireless clients. Improved client connectivity. Improved AP stability. Bugfixes Fixed DHCP failures for default network EAP/PPSK clients. Fixed an issue where mDNS/multicast service discovery could break after configuration changes or AP reboot. Fixed multicast streams sometimes not reaching wired clients on non-default VLANs. Fixed IPv6 connectivity issues on PPSK SSIDs after configuration changes or with multicast filtering enabled. Fixed hidden SSIDs appearing in Wi-Fi scan results. Fixed guest portal showing a blank page for clients. Fixed 10 Gbps ports not passing traffic after reboot or link events. Additional information INFO: U7-LR model support will be added in upcoming releases. ---- Update your devices by changing the Device Firmware Release Channel in the UniFi Network application to Release Candidate. If you wish to go back to the Official release after the upgrade, change the release channel back to Official. If you encounter any issues with this release, please provide us with some details on your setup and include the below information: AP model(s) Previous AP release version UniFi Network application version UniFi Console Support File (as private attachment)
