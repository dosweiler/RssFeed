      UniFi Access Point (all U7 and E7 models) 8.5.21

      Source: UniFi Access Point | Releases | Ubiquiti Community | Date: 2026-04-08 |

      Overview This release introduces Multi-Link Operation (MLO) Mesh support, specifically optimized for AirWire and UDB-Switch deployments. By leveraging MLO STR (Simultaneous Transmit and Receive), the mesh backhaul can now utilize multiple wireless bands simultaneously, improving throughput, latency, and link stability. To configure Mesh MLO STR UniFi Network 10.2+ required Mesh MLO operates on 5 GHz + 6 GHz bands Child devices with mesh MLO support: AirWire and UDB-Switch --- This release is promoted to Official/Stable release channel for these models: U7-Pro-XG, U7-Pro-XGS, U7-Pro-XG-Wall, U7-Pro-Wall, U7-Outdoor, U7-Pro-Outdoor, E7, E7-Campus, E7-Audience - April 13, 2026 U7-Pro-Max, U7-In-Wall, U7-Lite, U7-Mesh - April 17, 2026 U7-Pro - April 21, 2026 Improvements Improved client connectivity and roam events reporting. Improved automatic channel selection for 160 MHz bandwidth. Improved boot time. Stability improvements. Bugfixes Fixed authentication failures for Samsung A53 devices. Fixed SSIDs not broadcasting due to boot or configuration race conditions. Fixed IGMP/MLD querier being enabled. Fixed LED brightness control on U7 series devices. Fixed MLO peer inactivity and bulk roaming stability issues. Fixed multicast/broadcast blocker incorrectly dropping ARP requests. Fixed RADIUS CoA re-authentication timeouts. Fixed ARP proxy stopping after more than 30 IPv6-capable clients connected. Additional information INFO: U7-LR model support will be added in upcoming releases. ---- Important: If you encounter any issues, please share setup details and a support file. When possible, generate it before downgrading or power cycling, with Debug logs enabled. A support file from a working state is also helpful for comparison.
