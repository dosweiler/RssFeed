      UniFi Access Point 7.0.95

      Source: UniFi Access Point | Releases | Ubiquiti Community | Date: 2024-12-19 |

      Improvements Improved 2.4 GHz band connectivity and stability. Improved 5 GHz auto-channel selection. Improved Packet Capture feature. Improved TX Retries reporting. Improved connectivity at low signal levels. Improved stability. Bugfixes Fixed various mobile device 6 GHz connectivity issues. Fixed incorrectly reported disconnect events during client roam. Fixed AP going offline when the Network application is unreachable for some time. Additional information Please note that this firmware is not available for U7 Pro Max. We are actively working on adapting recent improvements for the U7 Pro Max and anticipate its release at a later date. To update your devices, set the Device Firmware Release Channel in the UniFi Network application to Official. If you encounter any issues with this release, please provide us with some details on your setup and include the below information: AP model(s) Previous AP release version UniFi Network application version Please post a support file as well
