      UniFi Access Point (all U7 and E7 models) 8.0.49

      Source: UniFi Access Point | Releases | Ubiquiti Community | Date: 2025-06-23 |

      Improvements Enabled wireless meshing for U7/E7 (with MLO enabled) to Wi-Fi 6/5 APs. Improved AP stability. Improved client connectivity. Improved wireless client roaming. Improved meshing performance in dense environments. Improved airtime utilization on the 5 GHz band. Improved MLO throughput in specific scenarios. Improved 6GHz auto-channel selection algorithm. Improved AFC position acquisition stability and prevented intermittent failures. Improved Ethernet stability on E7/U7 10GbE devices. Updated regulatory information for Brazil. Updated regulatory for Indonesia. Bugfixes Fixed empty airtime scan results for the 6 GHz band when operating in 320 MHz bandwidth. Fixed corrupted packet capture data. Fixed increased CPU usage when SNMP monitoring is enabled. Fixed RADIUS authentication issues when multiple servers are configured. Fixed RADIUS CoA not working in some environments. Fixed Intel AX210 wireless authentication failures over 6GHz (WPA3) on Linux. Fixed an issue where the AP stopped broadcasting when channels 12–13 were set for the 2.4GHz band in the United Kingdom. Fixed an issue where Multicast and Broadcast Control did not properly block traffic between clients connected to the same AP and on the same band. Fixed IPv6 RA VLAN leak between clients on the same AP. Fixed IPv6 leakage between SSIDs in certain scenarios. Fixed regression in IPv6 address assignment via SLAAC. Fixed communication between non-MLO devices on MLO wireless networks. Fixed incorrect Ethernet statistics reporting on dual-port devices. Fixed various reporting issues. Additional information If you encounter any issues with this release, please provide us with some details on your setup and include the below information: AP model(s) Previous AP release version UniFi Network application version UniFi Console Support File (as private attachment)
