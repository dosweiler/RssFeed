  • 2025-12-12

      UniFi Access Point (all U7 and E7 models) 8.3.2

      Source: UniFi Access Point | Releases | Ubiquiti Community | Date: 2025-12-12 |

      Overview This release is promoted to Official/Stable release channel for these models: U7-Pro-Max, U7-Lite, U7-Outdoor, U7-Pro-Wall, U7-Pro-XG, U7-Pro-XGS, U7-Pro-XG-Wall - December 17, 2025 U7-Pro, U7-Pro-Outdoor, U7-In-Wall, E7, E7-Campus, E7-Audience - December 19, 2025 Improvements Improved client connectivity in MLO mode. Improved RADIUS failover mechanism for enhanced reliability. Improved AP stability. Added 6 GHz regulatory support for Ukraine. Added 6 GHz regulatory support for Pakistan. Updated 6 GHz regulatory compliance for South Korea. Bugfixes Fixed an issue where IPTV services did not function correctly when connected through U7-IW switch ports. Fixed an Ethernet link negotiation issue occurring after device reboot or firmware upgrade on models with 10G ports. Fixed an issue where Guest Portal clients were unable to obtain a DHCP IP address. Fixed an issue where devices appears as offline when a large number of blocked clients were configured. Fixed an issue where connectivity would fail on E7-Audience when MLO was used. Fixed an issue where E7-Audience would stop broadcasting 6 GHz after configuration changes. Additional information INFO: U7-LR model support will be added in upcoming releases. ---- Update your devices by changing the Device Firmware Release Channel in the UniFi Network application to Early Access. If you wish to go back to the Official release after the upgrade, change the release channel back to Official. If you encounter any issues with this release, please provide us with some details on your setup and include the below information: AP model(s) Previous AP release version UniFi Network application version UniFi Console Support File (as private attachment)
