      UniFi Access Point for U7-LR 8.0.77

      Source: UniFi Access Point | Releases | Ubiquiti Community | Date: 2026-10-02 |

      Improvements Added Multi-Link Operation support for Virtual Network Override. Added support for RADIUS servers specified by FQDN. Improved access point stability. Bugfixes Fixed missing interference data in RF scan results. Fixed incorrect EHT rate reporting in the Network application. Fixed multicast traffic statistics showing zero in the Network application. Fixed wireless uplink failing to reconnect after receiving a deauthentication. Fixed MLO clients losing internet connectivity when using Dynamic VLANs. Fixed 160 MHz channel support in India. Fixed WiFi networks failing to broadcast after applying a WiFi network to all access points. Fixed clients disconnecting when changing their IP address using Network Override. Fixed WPA3-Enterprise Transition Mode preventing WPA2-Enterprise clients from connecting. Fixed several Proxy ARP connectivity issues, including with PPSK networks. Fixed transmit power settings not being honored by TPC. Fixed 2.4 GHz DTIM settings not being applied correctly. Fixed channel width and spatial stream settings not synchronizing with the uplink access point. Additional information Update your devices by changing the Device Firmware Release Channel in the UniFi Network application to Release Candidate. If you wish to go back to the Official release after the upgrade, change the release channel back to Official. If you encounter any issues with this release, please provide us with some details on your setup and include the below information: AP model(s) Previous AP release version UniFi Network application version UniFi Console Support File (as private attachment) AP Support File (as private attachment)
